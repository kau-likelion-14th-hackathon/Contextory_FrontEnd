# Frontend

## 실행 방법

```bash
npm install
npm run start
```

## 환경 변수

`.env.example`을 참고해서 루트 경로에 `.env` 파일을 생성합니다.

```env
EXPO_PUBLIC_API_BASE_URL=
```

## 폴더 구조

```txt
src/
├─ app/        # 앱 진입점
├─ screens/    # 화면 단위 컴포넌트
└─ shared/     # 공통 컴포넌트, 상수, 타입, API 설정
```

## 현재 세팅 범위

아직 해커톤 주제가 확정되지 않았기 때문에 최소 세팅만 진행했습니다.
